## 优化：拆分测试项目 + 升级 net8.0（同日上午后续）

- 目标：把 xunit/MSTest/NUnit 三种测试拆到独立测试项目（让 `dotnet test` 能发现全部测试），并消除 net6.0/Node20/ubuntu-latest 告警。
- 结构改造：
  - 主程序移到 `src/ConsoleApp1/`（net8.0 Exe，仅 Program.cs）。原因：原主项目在仓库根，SDK 默认 `**/*.cs` glob 会把 `tests/` 下测试文件一并编译，导致测试框架命名空间找不到。
  - 新增 `tests/ConsoleApp1.Tests.Xunit`(xunit 2.9.3)、`tests/ConsoleApp1.Tests.MSTest`(MSTest 4.4.1)、`tests/ConsoleApp1.Tests.NUnit`(NUnit 4.1.0) 三个独立测试项目。
  - 生成 `ConsoleApp1.sln` 串起四个项目；workflow 改为 `dotnet ... ConsoleApp1.sln`。
- 踩坑记录：
  - NUnit 4.6.x（4.6.0/4.6.1）公共 API 用了 C#14 `extensions` 特性，net8.0 默认 C#12 编译不过 → 降到 **NUnit 4.1.0**（C#12 兼容）。
  - NUnit 4 移除了经典 `Assert.AreEqual`，改用 `Assert.That(actual, Is.EqualTo(expected))`；已修改 NUnit 测试文件。
- 工作流优化：`ubuntu-latest`→`ubuntu-24.04`（规避 10/19 迁移告警），`actions/checkout@v4`/`setup-dotnet@v4`→`@v5`（规避 Node20 弃用告警），`6.0.x`→`8.0.x`。
- 验证：commit d869982 已 push；run 37035609930 结论 success，`build-and-test` 通过，**3 个测试项目各 1 个测试全部 Passed（共 3/3）**，Build 0 警告 0 错误，运行无 ANNOTATIONS 告警。
